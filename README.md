# TapCat - 点击猫咪游戏

一个简单的Unity游戏项目，玩家通过点击猫咪让它跳踢踏舞。

## 🎮 游戏简介
- **游戏名称**: TapCat
- **游戏类型**: 休闲点击游戏
- **开发引擎**: Unity 2021.3.13f1
- **目标平台**: Windows (可扩展至其他平台)

## 🚀 快速开始

### 1. 打开项目
1. 使用Unity Hub打开项目
2. 选择Unity 2021.3.13f1版本
3. 打开项目文件夹：`C:\Users\User\.openclaw\workspace\TapCat_New`

### 2. 设置场景
在Unity编辑器中：
1. 点击菜单：`Tools/TapCat/快速设置场景`
2. 系统会自动创建TapCat对象和UI

### 3. 运行测试
在Unity编辑器中：
1. 点击菜单：`Tools/TapCat/进入测试模式`
2. Unity会自动设置场景并进入播放模式

## 🎯 游戏功能

### 核心功能
- ✅ 键盘点击（空格键）
- ✅ 鼠标点击（左键点击猫咪）
- ✅ 踢踏舞动画
- ✅ 点击计数
- ✅ 状态显示
- ✅ 舞蹈状态切换

### 控制方式
- **空格键**: 点击猫咪
- **鼠标左键**: 点击猫咪
- **R键**: 重置点击计数
- **D键**: 切换舞蹈状态

## 📞 技术支持

### 常见问题
1. **项目打不开**: 确保使用Unity 2021.3.13f1版本
2. **菜单不显示**: 重启Unity或重新编译脚本
3. **动画不播放**: 检查Animator Controller设置
4. **UI不显示**: 检查Canvas设置和层级

### 调试技巧
1. 查看Console窗口的错误信息
2. 使用Debug.Log输出调试信息
3. 检查组件引用是否设置
4. 验证输入系统设置
