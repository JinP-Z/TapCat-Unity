# TapCat 2D 动画游戏

## 项目概述
一个完全2D的猫咪动画游戏，使用Sprite序列帧动画系统，符合Unity 2D游戏规范。

## 核心特性
1. **纯2D Sprite系统** - 无3D Cube，无旋转，完全2D
2. **序列帧动画** - 使用10帧猫咪序列帧 (cat_anim_00.png 到 cat_anim_09.png)
3. **点击触发** - 空格键或鼠标左键播放完整动画
4. **固定帧率** - 0.1秒/帧 (10 FPS)
5. **点击计数** - 显示点击次数
6. **重置功能** - R键重置游戏状态
7. **屏幕UI** - 显示游戏状态和操作提示
8. **零配置** - 点击Play按钮即可运行

## 文件结构

### 核心脚本
1. **TapCat2D.cs** - 2D动画主控制器
   - 管理Sprite动画播放
   - 处理输入事件（空格键、鼠标左键、R键）
   - 控制动画帧率和序列
   - 更新UI显示

2. **TapCat2DSetup.cs** - 自动设置脚本
   - 自动创建UI画布
   - 自动创建猫咪对象
   - 自动连接UI和控制器
   - 自动设置2D相机

3. **TapCat2DSceneSetup.cs** - 场景设置脚本
   - 场景自动验证和配置
   - 创建占位图（如果缺少资源）
   - 提供编辑器和运行时工具

### 资源要求
1. **猫咪动画帧** - 10张PNG图片
   - 命名：`cat_anim_00.png` 到 `cat_anim_09.png`
   - 建议尺寸：128x128 或 256x256
   - 放置位置：`Assets/Sprites/CatAnimation/`

2. **UI资源** - 自动生成，无需额外资源

## 使用说明

### 快速开始（零配置）
1. 打开Unity项目
2. 确保猫咪动画帧在正确位置
3. 点击Play按钮
4. 游戏自动设置并运行

### 手动设置（如果需要）
1. **创建猫咪对象**：
   - 新建GameObject，命名为"TapCat2D"
   - 添加`TapCat2D`脚本组件
   - 将猫咪动画帧拖入`Cat Animation Frames`数组

2. **创建UI**：
   - 使用`TapCat2DSetup`脚本自动创建
   - 或手动创建Canvas和Text元素

3. **设置相机**：
   - 确保主相机设置为Orthographic（正交）
   - 相机位置：`(0, 0, -10)`
   - 正交大小：5

### 控制方式
- **播放动画**：空格键 或 鼠标左键
- **重置游戏**：R键
- **帧率设置**：可在Inspector中调整（默认0.1秒/帧）

## 技术规范

### 动画系统
- **类型**：Sprite序列帧动画
- **帧数**：10帧（cat_anim_00到cat_anim_09）
- **帧率**：0.1秒/帧（10 FPS）
- **播放方式**：每次点击播放完整序列

### 输入系统
- **触发方式**：键盘空格键、鼠标左键
- **重置方式**：键盘R键
- **响应类型**：按下立即触发

### UI系统
- **显示内容**：点击次数、游戏状态、操作提示
- **更新频率**：实时更新
- **布局方式**：Screen Space Overlay

### 2D规范
- ✅ 使用SpriteRenderer，无MeshRenderer
- ✅ 使用正交相机，无透视
- ✅ 无3D变换，仅2D位置
- ✅ 无旋转，仅Sprite切换
- ✅ 使用Canvas UI，无3D UI

## 故障排除

### 常见问题
1. **动画不播放**
   - 检查猫咪动画帧数组是否为空
   - 确保SpriteRenderer组件存在
   - 验证输入检测是否正常工作

2. **UI不显示**
   - 检查Canvas是否正确创建
   - 验证Text组件引用
   - 确保UI元素在屏幕范围内

3. **相机看不到对象**
   - 检查相机是否为Orthographic
   - 验证相机位置和正交大小
   - 确保Sprite在相机视锥内

4. **资源缺失**
   - 创建`Assets/Sprites/CatAnimation/`目录
   - 放置10张猫咪动画帧
   - 或使用占位图系统

### 调试信息
- 启用`Show Debug Logs`查看详细日志
- 检查Console窗口的输出信息
- 使用场景验证工具检查配置
